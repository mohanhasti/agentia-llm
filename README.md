# agentia-llm
LLM + Agentic Thinking


## Installation


1. Create and activate a virtual environment:
    - On Windows:
      ```
      python -m venv venv
      venv\Scripts\activate
      ```
    - On macOS/Linux:
      ```
      python3 -m venv venv
      source venv/bin/activate
      ```
2. Install required dependencies:
    ```
    pip install -r requirements.txt
    ```
```markdown
# Create a `.env` file

```
## Usage

Run the chatbot CLI using the following command:
```
python chatbot.py
```
This will launch the command-line interface for interacting with the chatbot.
